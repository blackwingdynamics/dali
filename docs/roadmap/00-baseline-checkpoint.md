## Existing evidence boundary

The baseline inherits the previously recorded F405 evidence only:

- boot, clock, GPIO, SDIO, FAT32, AMRN loading, and application execution;
- bounded watchdog timeout and Safe Mode recovery;
- documented feature-gated MPU/context-switching and fault evidence;
- documented limitations for arbitrary DMA isolation, pre-reset Secure Boot,
  production multi-application policy, and cross-target portability.

The canonical records are:

- [`docs/testing/f405-silicon.md`](../testing/f405-silicon.md);
- [`docs/mvp-acceptance/recorded-evidence.md`](../mvp-acceptance/recorded-evidence.md);
- [`docs/boards/stm32f405/hardware-evidence.md`](../boards/stm32f405/hardware-evidence.md).

No new board flash, console capture, or physical acceptance run was performed
for this checkpoint. The next hardware-dependent foundation change must build,
flash, and compare its trace with this recorded implementation baseline.

- parked branches and historical hardware evidence.
